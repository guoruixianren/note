# VocoType

> 安全、离线的极速语音输入法，专为中文用户打造，同时支持英文。

## 基本信息

| 项目 | 详情 |
|------|------|
| GitHub | https://github.com/233stone/vocotype-cli |
| 官网 | https://vocotype.com |
| 开发语言 | Python / 私有桌面端 |
| 开源协议 | CLI 版 MIT；桌面版闭源 |
| 最新状态 | 积极维护（2024） |

## 支持平台

| 操作系统 | 支持情况 | 最低版本要求 |
|---------|:-------:|------------|
| Windows | ✅ | Windows 10 64位 |
| macOS | ✅ | macOS 11（Big Sur） |
| Linux | ⚠️ | CLI 版可尝试，桌面端不支持 |

## 核心特性

- **100% 本地离线**：所有语音识别在本地完成，数据不离开设备
- **极速识别**：官方声称识别延迟约 0.1 秒
- **AI 文本润色**：自动纠错、优化表达，支持摘要生成
- **自定义词典**：可添加专业术语、人名、品牌词
- **音视频转录**：导入音频/视频文件进行批量转录
- **SRT 字幕导出**：输出带时间戳的字幕文件
- **中英双语**：普通话优化为主，英文识别兼顾

## 输入法框架依赖

**无需任何输入法框架**。VocoType 通过系统剪贴板或模拟键盘将文字注入当前活动窗口，与操作系统直接交互。

## 语音引擎

- 私有本地引擎（基于 Sherpa-ONNX 或自研 ASR 模型）
- 不依赖 OpenAI API 或其他云服务

# 桌面版：前往官网下载安装包

## 优缺点

### 优点
- 中文识别质量高，针对普通话深度优化
- 完全本地运行，隐私保护好
- AI 润色功能减少后期编辑工作量
- 支持音视频文件批量转录

### 缺点
- 桌面端闭源，无法自定义或审计代码
- Linux 支持较弱（仅 CLI 版）
- 不支持 Fcitx5 等输入法框架深度集成

## 适用场景

- 中文用户日常写作、邮件、文档
- 需要 SRT 字幕的视频创作者
- 对隐私有严格要求的用户（不想联网）
