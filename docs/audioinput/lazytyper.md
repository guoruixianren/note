# LazyTyper

> 快速、准确、免费的多语言语音输入应用，支持 12 种 AI 语音模型（含 5 种离线模型）。

## 基本信息

| 项目 | 详情 |
|------|------|
| 官网 | https://lazytyper.com |
| 开源情况 | ❌ 非完全开源（免费闭源产品） |
| 最新状态 | 积极维护（2024） |

> ⚠️ LazyTyper 是免费应用，但**非开源软件**，无公开 GitHub 仓库。

## 支持平台

| 操作系统 | 支持情况 | 最低版本要求 |
|---------|:-------:|------------|
| Windows | ✅ | Windows 10 64位 |
| macOS | ✅ | macOS 11（Big Sur） |
| Linux | ❌ | 不支持 |

## 核心特性

- **12 种 AI 语音模型**：包含云端和本地（离线）模型，用户可自由切换
- **5 种离线模型**：包含 Whisper 系列等，可完全本地运行
- **高准确率**：官方宣称 90%+ 准确率，对技术词汇和代码识别良好
- **多语言支持**：基于 Whisper 的 99+ 语言，原生支持混合语言输入（如中英混合）
- **轻量级**：应用体积约 10 MB，启动快速
- **无广告**：纯净体验，数据留在用户选择的 API 提供方
- **快捷键激活**：全局热键触发录音
- **技术/代码词汇识别**：针对开发者场景优化

## 输入法框架依赖

**无需任何输入法框架**。使用操作系统原生 API 注入文字。

## 语音引擎

| 引擎类型 | 数量 | 代表模型 |
|---------|:----:|---------|
| 本地/离线 | 5 种 | Whisper tiny/base/small、本地 Whisper 变体 |
| 云端 | 7 种 | OpenAI API、Groq、Assembly AI 等 |

## 优缺点

### 优点
- 零门槛安装，小白友好
- 12 种模型灵活切换，适合不同场景
- 无广告、无订阅费用
- 混合语言识别体验好（适合中英双语用户）
- 技术/代码词汇识别优于一般工具

### 缺点
- **非开源**，无法审计代码
- **不支持 Linux**
- 商业授权需额外确认
- 社区支持相比开源工具较弱

## 适用场景

- Windows / macOS 用户日常文档撰写
- 开发者代码注释、技术文档的语音输入
- 中英混合语言用户
- 对安装配置不感兴趣、追求开箱即用的用户
